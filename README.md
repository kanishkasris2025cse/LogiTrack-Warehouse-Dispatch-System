# Kyowa Logistics - Automated Warehouse & Dispatch Audit System

## Overview
A lightweight system improvement tool designed to automate inventory auditing, batch stock synchronization, and dispatch order verification for warehouse and transportation logistics.

## Key Features
- **Relational Data Management:** Implemented normalized schema rules and SQL triggers for automatic stock reconciliation.
- **Dispatch Integrity:** Built inventory threshold checks to prevent over-dispatching and logistical errors.
- **Automated Audit Reports:** Provides immediate status indicators for low stock levels to optimize reorder cycles.

## Tech Stack
- **Database & Query Language:** SQL (SQLite / Relational Schema)
- **Application Logic:** Python (System Automation)
- **Version Control:** Git & GitHub
